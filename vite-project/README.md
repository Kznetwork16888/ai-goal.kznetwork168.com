# ⚽ Kznetwork168 世界盃 AI 戰隊 (Kznetwork168 AI World Cup)

一個專為企業與個人設計的互動式 AI 知識培訓與闖關遊戲。透過足球射門動畫、觀念解析說明、AI 卡牌道館 Boss 對戰與 STAR 專訪框架，讓使用者在遊戲中學習與評估 AI、LLM、RAG、Agent 與 Prompt Engineering 知識。

---

## 🌟 專案亮點與關卡機制

本專案包含三大關卡與完整生動的遊戲體驗：

### 🏆 第一關：練習場選拔 (Practice Field Selection)
- **8 球定生死**：從 22 道專業 AI 題庫中隨機抽取題目。
- **生動足球射門與守門員防守動畫**：
  - ⚽ **答對進球**：足球員擺腿起腳，足球劃出弧線飛入右上角死角，守門員撲空跌倒，跳出 `GOAL! ⚽ 成功進球！` 特效！
  - ❌ **答錯攔截**：足球員起腳，足球飛向中央，守門員跳起雙手攔截擋球，跳出 `SAVED! ❌ 守門員攔截！` 特效！
- **💡 觀念解析與解答說明 (Explanation)**：
  - 每次答題後展開詳盡解答說明。
  - **答錯停留時間加倍**：答錯時「下一題」按鈕倒數 3 秒後解鎖（`請閱讀解答說明 (3s...)`），強化學習效果。
- **💯 百分制分數系統與三段式評等 (Score Tiers & Soccer Graphics)**：
  - `< 60分`：`不及格，需多努力學習 😢`（顯示 ⚽️⚡ 破網/灰暗足球圖形）
  - `61 ~ 80分`：`漸入佳境，懂得運用 ⚽️`（顯示 ⚽️✨ 閃亮藍銀足球圖形）
  - `81 ~ 100分`：`大神降臨，難不倒你 🔥👑`（顯示 ⚽️🔥👑 黃金王者火球圖形）
- **🔄 再重玩一次 (Replay)**：結算畫面提供重玩按鈕，點擊立即可重新洗牌挑戰。

---

### 🏟️ 第二關：AI 卡牌道館對戰 (AI Card Dojo Match)

第二關採用完整的二階段 RPG 對戰機制：

#### 1. 階段一：隊伍籌備 (Select 4 Tools)
- **直覺 1-Click 卡牌點選與取消機制**：
  - 點擊卡牌切換選取/取消選取，卡牌右上方即時標註選取次序（`✓ #1` ~ `✓ #4`）。
  - 選滿 4 個 AI 工具卡牌即可點擊 **`開啟 AI 卡牌道館對戰，迎戰 Boss ➔`** 進入對戰階段。

#### 2. 階段二：6 場 AI 道館 Boss 對戰 (Dojo Boss Battles 1/6 ~ 6/6)
玩家依序挑戰 6 隻代表不同 AI 能力的 Boss 怪物：

| 關卡 | Boss 名稱 | AI 分類領域 | 戰鬥情境與難題 | 正確對應技能卡 |
|:---:|---|:---:|---|---|
| **1/6** | **混沌文字獸** | GENERATIVE AI | 50 頁會議逐字稿 1 小時內整理成 5 點摘要 + 行動清單 | **結構化摘要** 📋 |
| **2/6** | **多步驟迷宮獸** | AI AGENT | 10 家競品官網抓價格、比較表且每週自動更新 | **規劃執行 (AI Agent)** 🎯 |
| **3/6** | **重複勞動獸** | AUTOMATION | 表單複製到 Excel 寄 Email 重複 50 次 | **系統串接** 🔗 |
| **4/6** | **幻覺資訊獸** | KNOWLEDGE BASE / RAG | 200 頁產品手冊快速尋找保固條款精準引用 | **引用回答 (RAG)** 🔍 |
| **5/6** | **純文字防禦獸** | MULTIMODAL AI | 3 天生出 10 張宣傳圖、30 秒影片廣告與配音 | **綜合多模態生成 (圖/影/音)** ⚡ |
| **6/6** | **數據竊影獸** | SECURITY & ETHICS | 各部門直貼免費 AI、私掛 Agent 撈檔防護 | **正規 RAG + 去識別化** 🛡️ |

- **出牌攻擊機制**：
  - 玩家點擊下方手牌出擊。
  - 💥 **擊中弱點**：對 Boss 造成爆擊（Boss HP 降為 0），並展開 `💡 觀念解析`，點擊進入下一個 Boss 道館戰。
  - ❌ **攻擊被抵擋**：玩家受到反擊血量減少，展開 `💡 觀念解析` 並開啟 3 秒閱讀倒數，之後可繼續挑戰。
  - 擊敗全部 6 隻 Boss 後點擊 **`🎉 通關全部道館戰！進入賽後專訪 ➔`** 推進至第三關！

---

### 🎙️ 第三關：賽後專訪 (Post-Match Interview)
- **STAR 訪談框架**：
  - **S**ituation (工作情境)
  - **T**ask (目標任務)
  - **A**ction (AI 工具應用行動)
  - **R**esult (預期效率或品質成果)
- **抽獎體驗**：完成 4 個 STAR 欄位後解鎖 Email 輸入與抽獎資格。

## 🛠️ 開發與本機啟動指南

### 1. 安裝依賴
在專案目錄 `vite-project` 下執行：
```bash
npm install
```

### 2. 啟動本機開發伺服器
```bash
npm run dev
```
啟動後瀏覽器會自動開啟 `http://localhost:3000` (或 `http://localhost:3001`)。

### 3. 建置生產版本
```bash
npm run build
```
